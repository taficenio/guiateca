# Guiateca

Biblioteca de guías y plantillas curadas.

## Cómo levantarlo
1. Instalá Node.js 20 o superior (https://nodejs.org).
2. Abrí esta carpeta en Visual Studio Code.
3. En la terminal: `npm install` y después `npm run dev`.
4. Abrí http://localhost:3000

## Seguir con Claude Code
Abrí Claude Code en esta carpeta. El archivo `CLAUDE.md` le explica el proyecto y la hoja de ruta.
Por ejemplo, pedile: "Seguí con el paso 1 de la hoja de ruta de CLAUDE.md".
